# FinLit Teens - Master Your Money

A financial literacy web app for teens (14-18) with interactive courses and board games.

## Features
- 6 Interactive courses (Compound Interest, Loans, Budgeting, Business, Trading, Financial Literacy)
- 3 Board games (Money Trail, Stock Market Challenge, Budget Battle)
- 3 Financial calculators (Compound Interest, Loan, Budget Planner)
- XP, Levels, and 10 unlockable badges
- Progress saved locally

## Usage
Open `index.html` in any browser. No dependencies needed.
